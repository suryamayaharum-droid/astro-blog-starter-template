# HARUM NOIR — site público

Site editorial público de desenho, carvão, figura, observação e processo autoral.

## Estrutura pública
- Cadernos de Presença
- Ateliê Aberto
- Temporadas
- Carta do Ateliê
- Arquivo Aberto
- Sobre

## Princípio
O site publica somente material autoral ou conteúdo curado para circulação pública. Pesquisa bruta, benchmarking, mapas internos e inteligência editorial não fazem parte deste repositório público.

## Imagens
Os visuais principais desta versão são SVGs originais do próprio projeto e não dependem de thumbnails externas.

## Build
```bash
npm ci
npm run build
```
